# Fundus Focus: Multiple Eye Diseases Detection Using CNN
This project focuses on the detection of multiple eye diseases from retinal fundus images using deep learning. The aim is to build an accurate and reliable diagnostic aid that can support ophthalmologists and enable early intervention.

🔍 Key Features

Deep Learning Models Implemented (PyTorch):

VGG19,DenseNet121, MobileNetV2, GoogleNet, Resnet152, EfficientnetB80,RegNetY-32gf, 

Performance:

Achieved ~93% accuracy across all seven models (with small differences of 0.2–0.3%).

Dataset:

Used a Bangladeshi retinal fundus image dataset for training and evaluation.

Platform:

Training and experimentation performed on Google Colab (GPU) using PyTorch.

⚙️ Tools & Technologies

PyTorch for deep learning model implementation

Google Colab for training & evaluation

OpenCV, NumPy, Pandas for preprocessing and data handling

🚀 Current Status

Baseline results achieved with seven models.

Consistent accuracy of ~93% indicates strong potential for clinical application.

Currently exploring further improvements and fine-tuning.
